# Kärcher Filter Adapter for Corvette 364

Replacement filter for Corvette 364 is no longer available.  
This adapter allows using a standard Kärcher filter instead.

## Problem
Original filters for Corvette 364 are out of production and impossible to find.

## Solution
Designed a mounting adapter from scratch using reverse engineering.  
Printed on FDM printer. Fits on first try.

## What's inside
- `.m3d` — Kompas-3D V21 source files
- `.3mf` — print-ready files for any slicer
- Photos of installed adapter

## Details
- Designed in: Kompas-3D V21
- Material: PETG
- Print method: FDM

## Result
Filter sits tight. Flange fits the vacuum mount perfectly.  
Clamp nut holds the filter securely.
